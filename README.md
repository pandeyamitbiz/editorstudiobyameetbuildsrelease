ameetbuilds Studio
AI reel editor for Hinglish creators, by @ameetbuilds. Windows desktop app.

Download: open Releases and run ameetbuilds Studio Setup x.y.z.exe. The app updates itself from this page.

Windows 10/11, 64-bit. Windows may show "unknown publisher" because the installer is not code-signed yet: choose More info, Run anyway.
This repository contains no source code, only the README and the installers.
Third-party: FFmpeg is bundled (see its licence at https://ffmpeg.org/legal.html).
